The dashboard was built by following this YouTube tutorial:

```text
https://www.youtube.com/watch?v=fZn83JRt4Nk
```

Because the dataset was picked from a tutorial source, the safest GitHub approach is to credit the tutorial and avoid claiming ownership of the dataset.

## What Is Safe To Upload

Usually safe:

- README.md
- Dashboard screenshots
- Project description
- Cleaning steps
- DAX measures

Use caution:

- Raw CSV / Excel dataset
- `.pbix` file if it contains embedded dataset rows

## Recommended Credit Text

```text
This project was created for learning and portfolio purposes by following a YouTube Power BI tutorial:
https://www.youtube.com/watch?v=fZn83JRt4Nk

Dataset credit belongs to the original tutorial/dataset provider. This repository is not claiming ownership of the original dataset.
```

## If You Find The Original Dataset Link

Add:

```text
Dataset Source:
License:
Author:
```

If the license is unclear, do not upload the raw dataset. Link to the original source instead.
